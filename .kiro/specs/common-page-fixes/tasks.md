# 공용 페이지 수정 사항 구현 계획

## 개요

공용 페이지 수정 사항을 단계적으로 구현합니다. 메인 페이지 캘린더 기능 개선, 일정표 체크박스 동작 검증, 정보 수정 모달 UI 개선, 프로필 UI 개선, 커뮤니티 페이지 전면 재설계를 포함합니다.
